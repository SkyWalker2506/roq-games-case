# Case 1 çalışma arşivi

Bu klasör, elle düzenlenen son `FitTheShape` sahnesine ulaşırken alınan görsel kontrol karelerini ve kısa sekans kaydını saklar. Bunlar Unity sahnesinin çalışma zamanı bağımlılığı değildir; karşılaştırma, geriye dönük inceleme ve diğer case'lerde tekrar kullanılacak görsel dersler içindir.

- `CASE1_SON*.png`: son iterasyonların tam ekran kareleri
- `CASE1_KAMERA*.png`, `CASE1_ACILAR*.png`: kamera ve kompozisyon denemeleri
- `CASE1_TEPSI*.png`, `CASE1_ON_SIRA*.png`: tepsi ve ön sıra kontrolleri
- `CASE1_DALGA.png`, `CASE1_DOLUM.png`, `CASE1_WAVE.png`, `CASE1_YILDIZ.png`: hareket/VFX incelemeleri
- `CASE1_DUNYA.png`, `CASE1_GERI*.png`, `CASE1_ONE_GECEN.png`: dünya yerleşimi ve karşılaştırma kareleri
- `CASE1_SEKANS.mp4`: Case 1 sekans kontrol kaydı

Son elle düzenlenmiş sahne `ef0b8c8` commit'indedir. Case kurma kodu bu sahnenin konumlandırma otoritesi değildir.
